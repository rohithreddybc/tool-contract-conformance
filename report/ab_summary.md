## 3. Deviation from pre-registration

Document: `experiments/analysis_plan.md sec 4`

experiments/analysis_plan.md sec 4 specifies ONE recorded trajectory per task, sourced from tau2's own orchestrator (a real LLMAgent + UserSimulator call through litellm). This project runs with no model and no API credentials anywhere (CLAUDE.md); a prior run of this script (commit 94adf1e) confirmed that path cannot complete here -- record_trajectory failed on every attempted task with 'OpenAIException - Missing credentials'. DEVIATION: this run instead sources the action sequence from each affected task's OWN reference solution (task.evaluation_criteria.actions -- tau2's own gold trajectory, the same one EnvironmentEvaluator.calculate_reward itself replays to build the target/gold environment), executes it once against a fresh, unpatched, task-scoped environment via Tau2Adapter.record_reference_trajectory, and replays the identical recorded calls against as-shipped and patched tools with tau2's own EnvironmentEvaluator, unmodified. This is a STRENGTHENING of the plan's own determinism claim, not a weaker substitute: plan sec 5 says 'The model selected which trajectory exists; it plays no part in the comparison' -- here no model selects the trajectory either, so the model is removed from the evidence path entirely, including at recording time. It remains a deviation from a committed, pre-registered document and is recorded as such here, not silently substituted.

## 9. Sample size is provisional — rerun required before this result is cited

Recorded 2026-08-28 by the session owner, not by `ab_run.py`.

N=5 per finding is too small to carry the claim in §8. The exercise rate is 0/10, and at that N it cannot distinguish "these defects are latent under gold action sequences" from "we happened to sample five tasks." The distinction matters: the first is a finding about the benchmark, the second is a statement about our patience.

Unlike the pre-registered design, this mode has **no model and no per-run cost**. The sequences are deterministic and the only constraint is wall-clock, so there is no methodological reason to stop at five. The plan's own rule applies: run the whole frame if it completes in reasonable time, and otherwise take a seeded sample fixed before looking at any outcome.

**Required before any number here enters the paper:** rerun with the full F3 population (7 tasks — trivially exhaustive) and a substantially larger F2 sample or the full 1120. The seed and N must again be fixed in advance.

**Why it was not rerun immediately:** a concurrent 465-item cosmic-ray run is saturating the machine, and `ab_run.py` aborts with `Tau2AdapterError: tau2 worker process closed its output unexpectedly` under that contention. That is a resource collision, not a defect in the experiment. The rerun is queued behind the open-world arm.

The N=5 result is retained as-is rather than deleted, so the rerun can be compared against it.
